
# 🎬 CineFilm

O CineFilm é um site para organizar filmes em uma lista pessoal. Nele, é possível cadastrar filmes, pesquisar, filtrar por gênero, marcar favoritos e acompanhar o progresso dos filmes assistidos.

## 📌 Sobre o projeto

O projeto foi desenvolvido como atividade escolar, utilizando HTML, CSS e JavaScript, com o objetivo de colocar em prática os conhecimentos aprendidos em aula.

## ✨ Funcionalidades

- Cadastro de novos filmes.
- Exibição de filmes em cards.
- Pesquisa de filmes pelo título.
- Filtro por gênero.
- Filtro por status.
- Marcação de filmes favoritos.
- Visualização de uma lista de favoritos.
- Alteração do status dos filmes.
- Remoção de filmes.
- Estatísticas do catálogo.
- Cálculo da média das notas.
- Barra de progresso dos filmes assistidos.
- Destaque para o filme com a maior nota.

## 🎞️ Catálogo de filmes

O CineFilm possui 30 filmes cadastrados inicialmente, organizados por diferentes gêneros e com informações sobre suas notas, status e favoritos.

Cada filme possui cinco propriedades:

- `titulo`
- `genero`
- `nota`
- `status`
- `favorito`

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Pronto! Agora é possível utilizar o CineFilm.
